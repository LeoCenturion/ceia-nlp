# Natural Language Processing I

AI-Specialization - UBA (Universidad Nacional de Buenos Aires)

## Desafio 1: Document Vectorization and Classification
Natural language project focused on document vectorization and cosine similarity. Also a naive bayes classifier was used to classify documents based on their tfidf vector
Notebook: [desafios/d1/desafio_1.ipynb](desafios/d1/desafio_1.ipynb)

## Desafio 2: NLP - Word Embeddings
![img1](https://en.wikipedia.org/wiki/File:Word_vector_illustration.jpg)
Natural Language Processing project focusing on word embeddings (Word2Vec) and text analysis using Gensim and NLTK. Explores vector representations of words from a large corpus.
Notebook: [desafios/d2/desafio_2.ipynb](desafios/d2/desafio_2.ipynb)

## Desafio 3: Text Generation with RNNs
![img1](https://en.wikipedia.org/wiki/File:Long_Short-Term_Memory.svg)\
Deep Learning project for text generation using Recurrent Neural Networks (RNNs/LSTMs). The model is trained on a corpus of classical texts (Homer, Plato, Aristotle) to generate new text in a similar style.
Notebook: [desafios/d3/desafio_3.ipynb](desafios/d3/desafio_3.ipynb)

## Desafio 4: Question-Answering Bot

Development of a Question-Answering (QA) Bot using sequence-to-sequence models with LSTMs, trained on conversational data.
Notebook: [desafios/d4/6- bot_qa.ipynb](desafios/d4/6- bot_qa.ipynb)
